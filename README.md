# Breakout

W Kavanagh & N Merchant. Summer 2024

## Controls

A/D, arrows or mouse to move the paddle right and left.
ESC to pause.

## Powerups

Big/small paddle (orange/blue)
Fast/slow ball (red/cyan)
Fireball (flame)
